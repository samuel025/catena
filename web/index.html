Credit passport

A score that follows you across chains.

Pools on different chains cannot see each other. Catena gives them one shared view of a borrower, and keeps every decision on-chain and auditable.

1

Pools emit events

Each pool announces Borrowed, Repaid (on time or late) and Defaulted. Nothing else is trusted.

2

The model scores

A reactive contract on Lasna updates six inputs and runs a small neural net in integer math. Every node gets the same answer.

3

Rules set the tier

The score proposes a tier. Hard rules decide what applies: a default zeroes everything, and limits climb one tier at a time.

4

Callbacks set quotas

The total limit is split into a fixed quota per chain and pushed to each pool, which rejects stale updates.

Monotone by constructionMore on-time repayments never lower a score. More late ones never raise it.
Bounded exposureConcurrent draws cannot exceed the sum of the installed quotas, plus a borrower's own collateral.
Honest limitsTrained on synthetic data. A default reaches the other chain in about one to three seconds.
Catena

A hackathon prototype on test networks. Scores come from a model trained on synthetic data and are not real credit assessments. Explanations are model sensitivities, not definitive reasons.
